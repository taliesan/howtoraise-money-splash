# howtoraise.money

Private alpha landing page for the RaiseMoney.ai tool family, served via GitHub Pages at howtoraise.money.

`index.html` is a password-gated static page (the content is AES-encrypted client-side; enter the password to view). It links out to the live tools: the textbook, ProspectAI, StrategyAI, 100m Donor Notes, the RaiseMoney.ai workspace, and the MCP integration, plus the Funders on Fundraising podcast.
