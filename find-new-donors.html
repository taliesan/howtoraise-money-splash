Skills · Find New Donors
RaiseMoney.ai

Install Find New Donors in about five minutes.

This is token-intensive research and its depth scales with your context. It runs on any plan — the bigger yours, the deeper it digs before it has to stop.
1
Download

Get the skill file

Don’t unzip it — Claude takes the zip whole.

↓  find-new-donors.zip
2
Claude → Settings → Capabilities

Turn on code execution

Scroll to Code execution and file creation and switch it on. Skills won’t run without it.

3
Claude → Settings → Customize → Skills

Upload the skill

Click Add → Upload a skill and choose the zip. It appears in your list as find-new-donors.

4
In a new conversation

Ask for donors

No commands. Open a conversation and say:

“Find me new donors.”

Or upload a spreadsheet of your current donors and ask it to find donors not already on your list.

5
An hour or more

Then let it run

A full run visits hundreds of public web pages and verifies every identity before a name reaches you. That’s the point — it’s doing weeks of a researcher’s work in an afternoon. Expect an hour or more, with live updates throughout.

It won’t stop early and it won’t ask permission to keep going. If your session fills up, nothing is lost — say “continue the donor run” and it picks up exactly where it stopped.
